# 《香菜退散！》企劃書分析與待確認事項

**分析對象：** `香菜退散_Godot遊戲企劃書.md` v1.0
**用途：** 列出企劃書中的矛盾、缺口與風險，整理成需要決策的問題清單。每題都附上「建議預設」：在決策前，各角色先照預設進行，確定後再回頭更新。

---

## 1. 整體評估

企劃書已經很完整：設計支柱、MVP 範圍、Godot 場景樹、碰撞層、訊號、里程碑和驗收標準都有寫，也做了幾個正確的取捨（用檢查台模式取代自由物理抓取、香菜用預設掛點而不是程序生成、先做 PC 版）。

不過若要分給不同角色同時製作，下面四塊仍有缺口，會讓各角色做出彼此兜不起來的東西：

| 面向 | 現況 | 缺口 |
|---|---|---|
| 操作規格 | 有狀態表與按鍵表 | 狀態轉換條件不完整，部分輸入重複定義（見 2.1） |
| 評分規格 | 有權重 | 「誤夾」「探索度」「目標時間」都沒有可實作的定義（見 2.2） |
| 關卡資料 | 只有 `LevelData` 雛形 | 缺香菜配置、食物排列、隨機規則、驗證規則（見 2.3） |
| 內容規格 | 有料理與資產清單 | 牛肉麵的麵條和湯、遮擋型關卡的「移開」行為都沒定義（見 2.4） |

## 2. 發現的問題

### 2.1 操作與狀態機

1. **關卡 1-1 和狀態表互相矛盾。** 1-1 要教「點選香菜、挑除」，而且是明顯型（香菜在盤面上），但狀態表的 `Idle` 不能點香菜，只能先拿起食物再進入 `Inspecting`。結果是：要嘛 1-1 必須先教拿取（和 1-2 重複），要嘛 `Idle` 也要能直接挑除。
2. **左鍵拖曳的意義重複。** 按鍵表寫「拿起食物或移動餐具」，但 MVP 建議是「點選後食物自動移到檢查位置」，用不到拖曳。餐具到底是跟著游標移動，還是點擊後自動飛過去，也沒有定義。
3. **`Idle` 寫了「旋轉鏡頭」，卻沒有對應的輸入。** 右鍵拖曳只用來旋轉檢查中的食物；11.3 又說預設是「固定桌面鏡頭」。這兩處要統一。
4. **`Inspecting` 和 `ToolActive` 的切換條件沒寫。** 是點到香菜就自動進入 `ToolActive`？還是要先按 1／2 選餐具？目前不選餐具會發生什麼事？
5. **暫停與 `Resolving` 的關係沒寫。** 動畫播放中按 Esc，Tween 要不要暫停？恢復後計數會不會重複？
6. **「放回食物」的輸入沒定義。** 是再點一次食物、點空白處、按右鍵，還是有專門的按鈕？

### 2.2 評分系統

7. **精準度（25%）沒有對應的機制。** 「誤夾一般配料」需要射線能打到「非香菜但長得像」的物件（蔥花、青菜），但 7.2 規定 `ToolActive` 時射線只查香菜層。所以必須新增「誘餌層」或「誤夾判定規則」，不然這 25% 永遠是滿分。
8. **兩種餐具在 MVP 沒有差異。** 7.4 寫「筷子與鑷子都能移除所有目標」，但 1-4 要教「使用鑷子精準挑除」。如果沒有差異，玩家沒有理由切換。
9. **探索度（10%）的「已檢查」沒有定義。** 拿起來就算？要轉過幾度？要看過背面？
10. **速度（15%）的目標時間不在 `LevelData` 裡。** 只有 `time_limit_seconds`（限時），沒有 `par_time`（標準時間）。
11. **提示會不會影響分數還沒決定**，`hint_limit` 卻已經是 3。
12. **星級門檻只說「固定門檻」**，沒有給數值。

### 2.3 關卡資料與資料流

13. `LevelData` 只有 `food_scene` 一個場景，沒有欄位描述「哪些掛點有香菜」「有幾組合法配置」「隨機種子」。
14. `target_cilantro_count` 和實際放置的香菜數可能對不上，需要載入時驗證。
15. 企劃書說「料理與關卡參數用 Resource 或 JSON」，又說「優先選 Resource」，建議直接定案為 Resource。
16. 沒有存檔需求：星級、解鎖進度要不要保存？存在哪裡（`user://`）？
17. 沒有主選單和選關畫面的場景，但暫停選單有「返回主選單」。

### 2.4 內容與美術

18. **牛肉麵的「麵條間」和「湯」很難做成可拿取物件。** 麵條是一團還是多條？湯是液體 shader 還是固定平面？香菜可以浮在湯面嗎？
19. **遮擋型需要「暫放區」。** 檢查台模式拿起再放回會回到原位，遮擋依然存在。上層食物要移去哪裡？
20. **1-6 綜合料理沒有對應的資產**：是三道料理的組合，還是新的套餐？
21. **香菜和誘餌太像會不公平，太不像又沒挑戰。** 色弱玩家只看綠色無法辨識，要定義輪廓和明度差異的量化標準。
22. 美術規格沒有面數、貼圖尺寸、材質數量、比例尺（1 單位 = ? 公分）的預算。
23. 資產清單只列音效 8–12 個，但資料夾結構有 `music/`，沒說要不要做 BGM、要幾首。

### 2.5 技術與流程

24. Godot 只寫「4.x 穩定版」，要指定小版本（例如 4.5.x）。
25. 「效能目標依硬體另訂」，至少要先定一個基準機型和 FPS。
26. 沒有自動化測試的決策（GUT／gdUnit4，或只做手動測試）。
27. 沒有版控規範：Git LFS 要不要用？`.import/` 和 `.godot/` 要排除。
28. 沒有寫團隊人數和分工方式（一個人兼多職、多人，或 AI 代理協作），這會影響交接文件要寫多細。

## 3. 待確認問題清單（附建議預設）

> 標 ★ 的題目會卡住 M1／M2 開發，請優先回覆。

### A. 操作

| # | 問題 | 建議預設 |
|---|---|---|
| ★A1 | `Idle` 狀態能不能直接挑盤面上的明顯型香菜？ | **可以。** 1-1 只教挑除，1-2 才教拿取 |
| ★A2 | 餐具怎麼移動？ | 餐具模型跟著游標的射線命中點移動（懸停在表面上方）；左鍵點擊後才播放夾取動畫 |
| ★A3 | 怎麼放回食物？ | 右鍵單擊（不拖曳）或點畫面的「放回」按鈕；拖曳超過 4px 才算旋轉 |
| A4 | 要不要開放鏡頭旋轉？ | MVP 不開放，只能縮放；`Idle` 狀態表刪掉「旋轉鏡頭」 |
| A5 | 沒選餐具時能不能挑除？ | 關卡開始自動選筷子，永遠有一把餐具在手上 |
| A6 | 暫停時正在播的動畫怎麼處理？ | 動畫跟著暫停（`process_mode` 設定），恢復後接著播；計數只在動畫結束時更新一次 |

### B. 評分與規則

| # | 問題 | 建議預設 |
|---|---|---|
| ★B1 | 「誤夾」怎麼判定？ | 新增 Layer 6「誘餌」（蔥花、青菜葉等）；在 `ToolActive` 點到誘餌或食物本體都算誤夾一次 |
| ★B2 | 筷子和鑷子的差異？ | 筷子：命中範圍大、速度快，**夾不起碎葉**；鑷子：命中範圍小，能夾所有目標 |
| B3 | 「已檢查」的定義？ | 拿起後累計旋轉 ≥ 150°，或背面朝向鏡頭超過 0.5 秒 |
| B4 | 提示影響分數嗎？ | 不扣分，但三星需要「未使用提示」或改為只扣探索度 |
| B5 | 星級門檻？ | 1 星：清完；2 星：總分 ≥ 70；3 星：總分 ≥ 90 |
| B6 | 限時關失敗怎麼處理？ | 時間到不判失敗，而是速度分為 0（符合「扣分但不失敗」原則）；正式的限時挑戰模式放 P2 |

### C. 內容

| # | 問題 | 建議預設 |
|---|---|---|
| ★C1 | 牛肉麵的麵條怎麼做？ | 做成 2–3 個「麵條團」可拿取物件，不模擬單根麵條；湯是不可互動的固定 shader 平面，香菜不放在湯面上 |
| ★C2 | 遮擋型要把上層食物移去哪？ | 新增桌面「暫放盤」，在檢查狀態點「移到暫放盤」；關卡結束前可以不放回 |
| C3 | 1-6 綜合料理是什麼？ | 用現有資產組成「滷肉飯＋水餃小盤」套餐，不新增模型 |
| C4 | 香菜模型的種類？ | 完整葉、小葉、碎葉三種，各有 2 個顏色變體 |
| C5 | 要不要 BGM？ | 1 首主選單、1 首關卡循環，可以用授權音樂 |

### D. 技術與製作

| # | 問題 | 建議預設 |
|---|---|---|
| ★D1 | Godot 版本？ | 固定一個 4.x 穩定小版本（例如 4.5.1），寫進 README 和 `project.godot` |
| D2 | 目標硬體與 FPS？ | 內顯筆電（例如 Intel Iris Xe）1080p 穩定 60 FPS |
| D3 | 自動化測試？ | 用 gdUnit4 或 GUT 測試純邏輯（計數、評分、狀態機、資料驗證）；互動部分用手動測試清單 |
| D4 | 美術資產流程？ | Blender → glTF 2.0（`.glb`）；大型二進位檔用 Git LFS |
| D5 | 存檔？ | `user://save.cfg`（`ConfigFile`），只存各關最佳星級與是否解鎖 |
| ★D6 | 團隊組成？ | 預設為「一位開發者＋ AI 代理分角色協作」，所以角色文件寫成可以直接當 prompt 使用 |
| D7 | 文件語言／遊戲語言？ | 文件用繁體中文；遊戲先做繁中，字串一律用 `tr()` 包起來，方便以後加英文 |

## 4. 建議對企劃書的修訂（確認後執行）

1. 2.3 狀態表：`Idle` 增加「挑除盤面上可直接看到的香菜」，刪掉「旋轉鏡頭」。
2. 2.2 按鍵表：左鍵改成「點擊選取／挑除」，拖曳只用在右鍵旋轉。
3. 7.2 碰撞層：新增 Layer 6「誘餌配料」、Layer 7「暫放盤」。
4. 7.4 判定表：寫入筷子與鑷子的差異規則。
5. 8.3 `LevelData`：增加 `par_time_seconds`、`placement_sets: Array[CilantroPlacementSet]`、`random_seed`、`decoy_count`。
6. 9.1 範圍：P1 增加「主選單／選關畫面」「本機存檔」。
7. 10 驗收：效能填入基準機型和 FPS。
