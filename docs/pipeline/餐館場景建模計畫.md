# 餐館場景建模計畫

**狀態：** 草案（2026-11-14，04 3D 美術）。只規劃，還沒開始建模。
**範圍：** 遊戲內的桌子、椅子、餐館室內，以及之後換成不同風格餐館的做法。料理、食物、餐具不在這份文件裡。
**依據：** 企劃書 4.1「構圖：料理為畫面主體，桌面道具只作陪襯」、4.2「場景 1 套」；`docs/roles/04_3D美術.md` 技術規格；D-20261023-01（先參考圖再 3D）、D-20261023-06（重複花紋用 Blender）；Tripo 正式資產必須用 Pro 生成（`docs/pipeline/tripo3d_料理建模流程.md` 10.1）。

**鏡頭能看到什麼（依 M5 截圖推測，需要程式提供最近與最遠縮放的截圖確認）：** 預設鏡頭從前上方約 55–60° 往下看。桌面佔畫面約 70%，上方露出後牆的磁磚牆裙與牆面下半，左右露出側牆、地板一角和椅子。天花板、後牆上半、桌子正後方以外的區域幾乎看不到。

**結論：** 畫面上影響最大的依序是 ①桌面材質 ②燈光與背景明暗 ③後牆下半與兩側 ④地板與椅子。預算和工時照這個順序分配，看不到的地方不做。

## 2. 第一個風格的方向（使用者 2026-11-14 確認）

遊戲內是「台式小吃店」（磁磚、紅凳、紅木牌），選關背景畫是「暖色木頭家庭餐廳」。兩者混在一起會不像同一個世界。使用者選定第一個風格為：

> **台式小吃店，暖木色調版。** 結構沿用遊戲內的小吃店（白磁磚牆裙、紅塑膠凳、紅木菜牌、紅磚地磚），桌面和木作改成參考圖的深暖胡桃木，燈光改成暖黃、四周稍暗。選關背景畫之後由 UI 依這個方向重畫，或保留當「店外／休息區」的感覺。

風格 ID 建議：`xiaochi`（台式小吃店）。風格 ID 會被關卡、程式、UI 引用，依命名權責由 02 遊戲企劃定案。

## 3. 讓料理更突出的場景規則（所有風格都要守）

這幾條和「料理呈現得更好」直接相關，換任何風格都不能違反：

1. **背景比料理暗、比料理灰。** 背景（牆、地板、遠處道具）的平均明度比桌面低 15–25%，飽和度比料理低。用燈光衰減和 `WorldEnvironment` 的霧或暗角做，不要靠把貼圖畫髒。
2. **桌面是中暗的暖色。** 白瓷碗、黃麵、綠香菜在上面都要清楚。桌面明度落在 30–45%（灰階；2026-11-14 實測 47% 時淺色香菜和木頭一樣亮，使用者決定壓暗），木紋對比低，木紋寬度不能和香菜碎葉一樣細，免得碎葉被木紋吃掉。
3. **鏡頭能看到的範圍內，桌面附近不放綠色。** 盆栽、綠色招牌只能放在遠處、而且降低飽和度。香菜是綠的，背景出現綠色會干擾尋找。
4. **桌面上不放裝飾道具。** 桌面 9×6 全部是遊戲區（企劃書 4.1）。調味罐、筷筒、紙巾等放在隔壁桌或牆邊。
5. **鍵光方向固定在左前上方。** 提示煙霧、香菜陰影、檢查畫面都已經照這個方向調過；換風格只能改顏色和強度，不改方向。
6. **灰階檢查。** 每個風格做完，都在預設鏡頭截一張灰階圖，確認料理、香菜、誘餌比背景醒目。

## 4. 可換風格的架構

### 4.1 原則

- **遊戲區不跟著風格變。** 桌面大小 9×6、桌面在 y = 0、桌面碰撞、`KillZone`、棄置碟、暫放盤的位置都由 `game.tscn` 管，每個風格共用。風格套組只提供外觀，不帶遊戲用的碰撞。這樣換風格不會影響物理、關卡和掛點。
- **一個風格 = 一個場景套組 + 一組材質。** 能只換材質就不換模型（例如同一組牆面模組，換磁磚顏色就是另一種店）。
- **模組化。** 牆、地板、飾條用固定格線拼，不再做一整塊背景。

### 4.2 場景套組的介面（給程式的約定）

每個風格是一個場景 `art/env/<style_id>/env_<style_id>.tscn`，由 3D 美術組裝，程式在 `game.tscn` 裡實例化成 `Environment` 節點。

```text
EnvSet_<style_id> (Node3D)       # 原點 = 桌面中心，y = 0 就是桌面
├── Table (Node3D)               # 只有外觀，桌面頂在 y = 0、範圍 9×6
├── Room (Node3D)                # 牆、地板、飾條、椅子、道具（只有外觀）
├── Ambience (Node3D)            # 選用：會動的東西（吊扇、蒸氣），暫停時要停
└── LightingPreset (Node)        # 指到 env_<style_id>_lighting.tres 與燈光設定
```

| 約定 | 數值 |
|---|---|
| 比例 | 1 單位 = 10 cm（同全專案） |
| 桌面 | 頂面 y = 0，可用範圍 9×6；桌緣與桌腳造型可以依風格改 |
| 地板 | y = -7.5（桌高 75 cm） |
| 房間 | 後牆在桌子後方 11 單位，左右牆在 x = ±15（沿用 M5，鏡頭已經依此調好） |
| 禁止區 | 桌面上方、桌面範圍外推 1 單位內不能有任何模型（避免擋到拿起的食物和餐具） |
| 碰撞 | 套組內不放碰撞；地板若需要接住掉落物，由 `game.tscn` 的 `KillZone` 處理 |
| 燈光 | 鍵光方向固定（第 3 節第 5 條），每個風格只提供顏色、強度、環境光、霧與暗角 |

要不要讓 `LevelData` 指定風格（例如 `env_style_id`），由 02 遊戲企劃與 06 程式決定。MVP 只有一個風格，可以先寫死。

### 4.3 模組格線

| 模組 | 尺寸（單位） | 說明 |
|---|---|---|
| 牆面 | 寬 10、高 30（1 m × 3 m） | 下半牆裙＋上半牆面＋飾條分成 3 層，可各自換材質 |
| 牆角 | 內角、外角各 1 | 接縫對齊 10 的格線 |
| 地板 | 10×10 一片，或整片平面加可接續貼圖 | 地磚用貼圖，不做幾何 |
| 開口 | 寬 10 或 20 | 門、窗、出菜口，換風格時換這些最有效果 |

### 4.4 命名與資料夾

沿用共用命名「類型_名稱_變體」，類型用 `env`，中間加風格 ID：

| 種類 | 規則 | 範例 |
|---|---|---|
| 風格專用 | `env_<style_id>_<名稱>_<變體>` | `env_xiaochi_wall_tile_a`、`env_xiaochi_stool_a` |
| 各風格共用 | `env_common_<名稱>_<變體>` | `env_common_floor_plane`、`env_common_light_tube_a` |
| 材質 | `mat_env_<style_id>_<名稱>` | `mat_env_xiaochi_trim` |
| 燈光預設 | `env_<style_id>_lighting.tres` | `env_xiaochi_lighting.tres` |

- 匯出：`art/models/env/<style_id>/`、共用件 `art/models/env/common/`
- 原始檔：`art/source/env/<style_id>/<style_id>.blend`、`art/source/env/common/env_common.blend`
- 現有的 `scene_table`、`scene_backdrop` 在第 1 階段由新資產取代，改名時通知程式改路徑。`scene_discard_dish`、`scene_temp_plate` 是遊戲物件，不屬於風格套組，名稱不變。

### 4.5 貼圖策略

- 每個風格 1 張 **trim sheet**（2048²）：牆裙磁磚、牆面、木飾條、地磚、木牌都從這張取，模組可以任意拼，材質數少。
- 每個風格 1 張 **道具調色盤／圖集**（1024²）：椅子、調味罐、菜牌等小道具共用。
- **桌面獨立 1 張**（2048×1366，沿用現有比例）：畫面上最大的面積，值得單獨一張。
- 換風格時優先換這 3 張貼圖。

**工具選擇原則：**
- **Blender：** 建築、模組、所有軸對稱的東西（凳子、鍋、罐子）、有重複花紋或文字的東西（磁磚、菜牌）。這些 Blender 做得比 Tripo 快、乾淨、能精準對齊格線（D-20261023-06 同理）。
- **Tripo（Pro 方案）：** 只用在不規則、有雕塑感、沒有重複花紋的點綴道具。照料理的流程：先用 GPT Image 2 產生參考圖、通過檢查後再生成 3D，寫進資產紀錄。
- **GPT Image 2 概念圖：** 第 1 階段先產生 2–3 張整體概念圖，當這個風格的「風格基準」（等同料理的牛肉塊 A），之後的模組和道具都對齊它。
- 文字（菜牌）一律自己排版做成貼圖，不讓 AI 生成文字。

## 6. 預算

| 項目 | 上限 | 說明 |
|---|---:|---|
| 整個場景套組三角面 | 25,000 | 整盤料理 ≤ 30,000，兩者加總仍遠低於 PC 負擔 |
| 單一道具 | 1,500（大型 3,000） | 看不清楚的小道具 ≤ 500 |
| 材質數（draw call） | ≤ 12 | 靠 trim sheet 和圖集；同材質的靜態模組在 Blender 合併後再匯出 |
| 貼圖 | 桌面 1 張 2048、trim sheet 1 張 2048、道具圖集 1 張 1024、Tripo 道具各 512 | 風格之間不共用的只有這幾張 |
| 動態物件 | ≤ 3 個 | 吊扇、電扇、蒸氣；暫停時全部停止（企劃書 Esc 規則） |

所有模組加第二組 UV（UV2），之後如果要用 `LightmapGI` 烘焙光影，不用重做。
